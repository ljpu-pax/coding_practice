# Coding Practice

A collection of coding problems and solutions organized by company and topic.

## Structure

- **Company-specific folders**: Contains problems from specific company interviews
  - `anthropic/`, `coinbase/`, `doordash/`, `linkedin/`, `robinhood/`, etc.
- **general/**: Miscellaneous practice problems and solutions
- **api_design/**: API design problems
- **ml/**: Machine learning related problems
